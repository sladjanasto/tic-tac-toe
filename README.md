# Pure CSS Tic Tac Toe

A fully functional, interactive Tic-Tac-Toe game built entirely in **SCSS and HTML** – no JavaScript involved.

## ✨ Features

- Pure CSS game logic
- Player turns handled by `:checked` and `:has()`
- Win/draw detection using SCSS maps
- Fully responsive layout
- Scalable grid structure

## 🛠 How It Works (Quick Overview)

> For the full technical explanation, check out the article below 👇

- The grid is generated using SCSS functions
- Each cell has two checkboxes (X and O)
- Labels act as clickable zones
- Player turns are managed by input state chains
- Winning combinations are precomputed with SCSS maps
